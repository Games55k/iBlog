# iBlog

A static blog template built [Astro](https://astro.build/) & [Fuwari](https://github.com/saicaca/fuwari).

## ⚡ Commands


| Command                    | Action                        |
|:---------------------------|:------------------------------|
| `pnpm install`             | 安装依赖                       |
| `pnpm dev`                 | 启动开发端口为 `localhost:4321` |
| `pnpm build`               | 打包到 `./dist/` 文件夹下       |
| `pnpm new-post <filename>` | 新建文章                       |
